# 🎃 Talking Jack-o'-Lantern

Turn an old Android phone into a talking jack-o'-lantern. Open the page in Chrome, paste a free Gemini key, pick a personality, and put the phone in a pumpkin. It hears visitors, talks back in character (Gemini Live voice), and flickers the flashlight and screen with its voice. Tap the screen to mute.

**Open it:** https://davisdilanchian.github.io/jack-o-lantern/

- Key: free from https://aistudio.google.com/apikey. It is stored only on your phone and sent only to Google.
- Best in Chrome on Android (flashlight control). Other browsers still talk and glow on screen.
- Tip: tape yellow or orange film over the flashlight, set volume to max, keep it plugged in.
